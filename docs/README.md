This folder serves as a record of all of the documentation regarding SortingVR. 

`./des156` contains submissions for my DES 156: UI/UX Design class.
`./devlogs` contains devlogs for every day I worked on the project.

`CREDITS.md` contains links to assets and documentation 

I am organizing these documents with an [Obsidian](https://obsidian.md/) Vault. I highly recommend it - it's a very good program to use for notetaking and organizing Markdown files!
