## Testing "Look and Feel"
* I ran the test and the whole thing worked, but there were some "look and feel" issues that need to be addressed:
---
1. Block placing is still finnicky. Sometimes when you place the block onto the slot it doesn't fully snap into place. 
2. CompareButtons aren't connected to the mechanism yet - that needs to be worked out. Not sure if this is a consequence of that, but pushing my hand into it doesn't depress it at all (at least not visibly). It could be because I'm not using the "skeleton" hand with individual rigidbodies for bones? 
3. The SliderRack's labels are all wrong - they're placed upside down. It looks like the sliders stack vertically (positive Y relative to the world) instead of horizontally (each additional slider moves away from the slots horizontally).
4. Everything is a little too big, to be honest. This whole user experience is kinda meant to be like a workbench, so you should have to walk 5 meters to get from one slot to the last one.
5. The pseudocode got obscured by the tall blocks - an idea that I was given is to have the pseudocode be a floating panel that you can move around, kinda like the windows in the regular Oculus UI.
6. Currently you're allowed to move the triangle handles for each of the sliders out of their "track" (the line on which they're meant to slide). This doesn't really feel natural - instead of the triangle moving out of place, your hand should maybe extend to a certain distance away, and if you extend too far away you automatically let go of the slider (kinda like Blade and Sorcery).
7. We don't have number labels for the slots - they should really have them so we know which index we point to (temp, 0, 1, 2, 3, etc.)
