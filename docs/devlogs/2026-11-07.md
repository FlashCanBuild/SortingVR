## Meta Horizon Link "incompatible hardware" banner

**Problem:** Meta Horizon Link showed "Your system's hardware is incompatible" whenever my Intel Arc iGPU was enabled. It only went away when I disabled Intel in Device Manager, which made my laptop run slowly.

**What I tried (no effect):**
- Set Meta processes to the NVIDIA GPU in Windows graphics settings
- Set the NVIDIA GPU as the global default in NVIDIA Control Panel
- Updated Intel drivers through Windows Update
- Re-enabling Intel after the app launched (the check re-ran and the banner returned)

**What I learned:**
- Meta's requirements page lists Intel Arc GPUs as unsupported by Link. The compatibility check looks at every adapter on the system, not just the one an app renders on. That's why per-app GPU settings and driver updates couldn't help.
- Other developers with hybrid Intel Arc + NVIDIA laptops report the same banner on Meta's forums.
- The banner isn't a hard block. With Intel enabled, Link still connected and Godot could see the headset. So I didn't actually need to dive too deep into this. Whoops!
