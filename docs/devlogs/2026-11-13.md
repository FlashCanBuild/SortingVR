## SortBlock
* A [grabbable](https://godotvr.github.io/godot-xr-tools/docs/pickable/) block that can be placed into a slot. It should inherit `pickable.tscn`, and it should have:
---
* A value `v` that is `1 <= v <= arr_len`.
	* ex: An array of 5 blocks should have blocks that are of value 1, 2, 3, 4, and 5.
	* This value should affect two things:
		1. The size of the block. A block's dimensions (length, width, height) should be `b, b, b * value` for some size `b`.
		2. The color of the block. The smaller the value, the redder the block. The larger the value, the bluer/purpler the block.
* Grab points - should be placed at the midpoint of the block's height, and one for each hand (left & right).
* Rigidbody3D and Mesh3D, obviously
* For the overall design, I'm thinking a beveled rectangular prism, with the number value on each rectangular face. Wondering if these meshes could be created with a script in Godot, as they're pretty simple? Or maybe we could make a quick Python script to generate them from 1 up to the number 20?
* Should be a part of the `SortBlock` group (see [[2026-11-13#Slot|Slot]]).
* Every block’s local origin should be its _bottom center_: the mesh and collision shape are offset up by half the height, and the grab points sit at `(0, height / 2, 0)` locally. Then every block snaps to the same point and rests on the slot’s surface at any height, and the slot needs no value-dependent logic.
