## Fixing Compare Buttons
* It feels like right now it's really easy to double-press a button accidentally and make a mistake - there should be some down-time where a button cannot be pressed (like 1 second maybe?)
* There also may be some logical errors with the `CompareStep`/`CompareAction`/`CompareButton` typescript files. I want to run a quick check to make sure it all makes sense.
	* What this could mean is printing a console log  upon every Step and Action:
	* `expected compare: true` or `expected set i 2`
	* `got compare: false` or `got set i 2`.
## Additional Issues
* `CompareButton`s work now. There weren't any logical errors with the `CompareButton` itself - just that we want a 1 second cooldown between button presses to ensure no accidental button presses occur.
* Some issues I did find though:
	* The `minIndex` slider is not updating - looks like `SetStep`s are automatically being completed.
	* Because hands are physical now, releasing a block causes the block to spawn within the hand's rigidbody, which flicks the block around. We could make fix this by making sure hands only physically interact with the compare button layer?
		* This issue also might cause the fact that placing blocks into slots is still difficult. I'll test placing blocks after we fix these collisions.
	* Also, I noticed that blocks can be picked up from farther away (the hand doesn't even need to be touching the block to pick it up). 
### Fixes
* For the `minIndex` issue I forgot that I had a debug mode on - whoops!
* For the hands, I removed the collision between the blocks and the hands. The only physical things that the hand needs to interact with are the buttons.
* I also decreased the grabbing range for the blocks so that it feels a little more realistic.
#### Fixing Slider Off-By-One and Vertical instead of Horizontal
* Currently, the sliders are stacked vertically instead of horizontally, and their indices are off by one (the left side is on index 0 instead of the "undefined" index -1.)
