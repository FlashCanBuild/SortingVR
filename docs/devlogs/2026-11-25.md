* Ran into this error: *"Script inherits from native type 'PanelContainer', so it can't be assigned to an object of type: 'Control'"*. My root node was a plain `Control`, but the script said `extends PanelContainer`. Changed the root's type and it was fine.
* The UI looked inconsistent (one button had a different margin than the rows). Turns out that's normal Godot: buttons draw their own padding from their StyleBox, and containers (not me) control layout. Fix is `MarginContainer` for padding, one `HBoxContainer` per row, matching minimum widths on the labels, and a shared `Theme` resource instead of per-node overrides.
## Floating Panel Grabbing
* I could grab the Pseudocode Panel from way farther away than before. Reason: `FloatingPanel` sized its hitbox to the whole screen, so reaching any part of it counted as grabbing it.
* Fix: shrink the pickable's collision shape to a thin handle bar under the screen (`handle_height`, `handle_gap`). The `Viewport2DIn3D` has its own body for pointing and poking, so UI clicking still works.
* Added a white `handle_mesh` that gets sized from the same shape so the visible bar and the hitbox can't drift apart.
* Tried adding `XRToolsGrabPointHand`s to the panel for a nicer hand pose, but that brought back the grab-from-afar problem, so I removed them again.
* Learned that **ranged grabbing** might be the real cause of grabbing things from far away: it's an `XRToolsFunctionPickup` setting that ranks pickables by angle, not by collision shape. Nothing in `Main.tscn` overrode it, so I was running on the addon defaults.

## Topics I Learned Today
* `.bind()` appends arguments *after* the signal's own arguments (`value_changed` gives `value`, then the bound `bus`). Same family as the `.connect(_on_button_pressed(true))` bug from last time.
* Linear vs. decibel volume: sliders go 0 to 1 and `linear_to_db` converts, but `linear_to_db(0)` is negative infinity, so mute the bus at zero.
* Frame-rate-independent smoothing: `1 - exp(-speed * delta)` instead of a fixed lerp weight, so the speed doesn't depend on 72 vs. 120 Hz.
* A script's `extends` has to match the node type it's attached to (or a parent of it in the hierarchy).
* Containers control layout. Size flags, minimum sizes, and Themes are how you shape it, not dragging nodes around.
